            @font-face {

            /* se usa este estilo cuando es cursiva */

Propiedades de los textos

Propiedades relacionadas con los textos

Práctica
  • color
  • font
    No aporta nada, es una abreviación. Se le puede dar múltiples valores simultáneamente, en vez de escribir mil propiedades y sus valores. Sintaxis: 
            font: [ <font-style> || <font-variant> || <font-weight> ]?  <font-size> [ / <line-height> ]? <font-family>
    Lo obligatorio son font size y font family, el resto se puede poner o no. Ejemplo: 
                p {font: italic 300 16px/1.25 Arial, Helvetica, sans-serif;}
  • font-family
  • font-size
  • font-size-adjust
    Se aplica cuando la fuente primera falla, entonces ajusta las siguientes. Ajusta la fuente en porcentaje de 1. Modo: 
                p {
                font-family: 'Trebuchet MS', 'Lucida Sans Unicode', 'Lucida Grande', 'Lucida Sans', Arial, sans-serif;
                font-size:32px;
                font-size-adjust:0.6;
            }
    Aquí sería el 60 % de 32px a partir de Lucida Sans Unicode.
  • font-stretch
    Habla de cuánto se condensa o expande la letra, modo en que las letras aparecen más o menos juntas. Mayormente para títulos. OBSOLETO, usar font-width.
  • font-style
  • font-variant
  • font-weight
  • line-height
    Es un porcentaje en base a 1 o en píxeles.
    Lo más normal es que sea hasta 1.5, porque si no, es demasiado visualmente.

Efectos sobre textos

  • letter-spacing
    Separa las letras, la variande de word-spacing hace los mismo cno plabras.
  • line-break
    Para cunado se hace un salto de linea automatico.
    • auto
      — Romper el texto usando la regla de salto de línea predeterminada.
    • loose
      — Romper el texto usando la regla de salto de línea menos restrictiva. Típicamente usada para líneas cortas, como en los periódicos.
    • normal
      — Romper el texto usando la regla de salto de línea más común.
    • strict
      — Romper el texto usando la regla de salto de línea más estricta.
    • anywhere
      — Existe una oportunidad de envoltura suave alrededor de cada unidad de carácter tipográfico, incluso alrededor de cualquier carácter de puntuación o espacios en blanco conservados, o en medio de las palabras, sin tener en cuenta cualquier prohibición contra los saltos de línea, incluso los introducidos por caracteres con el carácter GL, WJ o ZWJ class o exigido por la propiedad word-break. No se deben priorizar las diferentes oportunidades de envoltura. No se aplican guiones.
  • overflow-wrap
    Basicamente que baje lo que sobre. Por defecto es normal, pero se puede poner en anywhere y break-word.
  • hyphens
    para cuando hay wrap, y queremos que se partan las palabras con un guincito. Lo hay manual, pero hay qeu cambiar un html, y no lo veo productivo para responsive... asi qeu mejor por defecto poner auto lol.
  • text-align
    dentro de la aja contenedora se alinea el texto.
    Datos interesantes: justify all: afecta tambien a las ultimas lineas de parrafos. Asi qeu las risas con como queda.
    Also, con justify (solo, sin el alll) tambein se aplica a las lineas que tiene un br, asiq ue cuidadin con usar eso lol
  • text-align-last
    solo la ultima fila
  • text-decoration
    lineas que acompañan al texto. es abreviadad tambien. Sintaxis: 
            text-decoration: text-decoration-line || text-decoration-style || text-decoration-color ;
    Por defecto el color de la linea será del mismo que la letra que acompañe. Ejemplo: 
                text-decoration: underline dotted red;
    Se pueden poner lineas por arriba y por abajo y en medio al mismo teimpo.
  • text-indent Afecta la primera linea del parrafo, Si lo pones en positivo va ahacia la derencia y si está en negatiovo va pala izqu.
  • text-transform
    Cambia el texto seleccionado:
    • capitalize — Primera letra de cada palabra en mayúsculas, el resto de caracteres no es modificado.
    • uppercase — Todas las letras en mayúsculas.
    • lowercase — Todas las letras en minúsculas.
    • none — Evita cualquier cambio.
  • text-shadow Se puede hacer lo mismo al box. Valores mínimos: 
                    text-shadow: indexXlinea indexYcolumna radioDistorsion color
    Vamos con un ejemplo: 
                    text-shadow: 5px -5px 10px #000;
                text-shadow: 0 0 10px #000;
    la segunda es una sombra centrada sin desplazamiento, basicamente ueda modo halo. En realidad se podria eliminar el radio de distorsion y quedaria como si se hubiese escrito dos veces
  • white-space
    Como se tratan lso espcais en blanco. Aunque se le metan mil espacios en codigo soo se muestra uno en web,

  • word-spacing
  • word-wrap
