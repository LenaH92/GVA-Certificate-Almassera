Tablas

Link a practica

propiedades:

  • vertical-align
    solo funciona en la celda, permite alinear en vertical. Por defecto
    para alinear en horizontal, text align y sanSacabao
  • border-collapse
    si la lineas entre celdas contiguas estan unidas o no. Por defecto es separadas.
  • border-spacing
    establece la separacion entre las celdas.
    !! No funciona si el collapse esta en collapse. solo funciona si está separado.
  • empty-cells
    Se onsidera vacia cuando no tien contenido. no tiene que neer nada entre las etiquetas. modo <td></td> Y NO ESTO: <td> </td>!!!!!
    Anyway hace que no se vea nada, pero que no sustituya las celdas contiguas ese espacio. Valores: show || hide
  • caption-side
    Por defecto es arriba, pero se le puede poner bottom para ponerlo abajo.
    PAra hacer más cambios se pone en el css la eitqueta caption y a modificar
