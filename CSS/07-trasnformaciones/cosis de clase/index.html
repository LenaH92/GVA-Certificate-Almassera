Transiciones

Link a practica de transiciones

es un metdosa traves del cual se fuerza el cambio de uin valor de uina propiedad(o varias) de un punto inicial a un punto final en un determinado tiempo.
cuando se crean el sistema interpola lños puntos intermedios de la transición.
es importante especificar en la propiedad inicial ocmo esta originalmente para que calcule solo el cambio-

#dato, si se cambian las alturas y anchuras, afecta a los que los rodean.. para eso mejor usar transform: scale(xx0)

propiedades

  • transition-property
    puedes elegir que propiedades quieres que cambien, separadas por comas. Si no hay algo que no quieras que se anime en el cambio, se le puede poner all y se aplica a todas. Palante.
  • transition-duration
    se indica en segundos (s) o milisegundos (ms)
    cortas: 300ms, o 0.3s o largas 500ms+
  • transition-delay
    el retardo, lol. Vamos desde que se indica que empiece hasta que realmente empieza. Modo, con un hover, si le metes un delay al hover, si quitas el raton durante ese retraso la animacion no se llevaráa cabo.
    tambien se aplica a cuadno te quitas el raton btw
  • transition-timing-function
    digamos es como la transicion se lleva, que hayan picos de rapidez o lentitud.
    permite crear una de cero
    Web original con representacion grafica de los tiempos de cambio
    • ease
    • ease-in
    • ease-out
    • ease-in-out
    • linear
    • steps
      Se marcan puntos y se cambian en esos puntos de forma radical, sin animacion bonita I guess
    • steps-start
    • steps-end
  • transition
    propiedad que acumula tr-property tr-duration tr-timing-function tr-delay
