    - Ubica la caja segun su tip (sea inline o block) siguiendo el orden del código.
    !! las propiedades de top, right bottom or left dont work if static is on.
  • relative
    las cajas se posicionana igual al static. Se puede modificar la posicion del contenodor relativo usando top right left bottom. Toman una distancia qeu puedes ser positiva o negativa. UN valor positivo irá hacia el centro del elemento, por lo que si le pones 50 left se desplaza hacia 50 a la derecha

    toma como referencia el elemento padre que no tenga el posicionamiento estático. De no haberlo, coge el body.
    El elemento se posiciona de forma que flota, dejando de ocupar su espacio, el cual ocupará el elemento que venga (hermano).
    Funciona igual que el de antes pro con la diferencia de que puierde su ssitio y el 0 0 es el del padre que no tenga una posicion estática.
  • fixed
    la referencia es la pantalla del ordenador, necesita de estar posicionado bc otherwise desparece.
    el 0 0 es la esquina superior izquierda de la pantalla.
    !! Se queda en una posicion fija en la ventana del navegador sobre todo
  • sticky
    Una vez llega a la posicion en vertical que se especifique en top, se qeuda ahi para el resto de la pagina. 
                            position: sticky;
                        top: 0;
                        z-index: 500;

Valores de Display:
  • none - Desparese del flujo del codigo. aka no se ve ni ocupa hueco.
  • inline - se comporta en elemento enlinea. porops de width y height no se aplican
  • inline-block- se comporta en elemento enlinea. !!! PERO porops de width y height SÍ aplican
  • block - elemento se comporta conmo modo bloqeu
  • inline-flex - el contenedor se comporta inline block y los hijos (flexitems) se comportan según flex.

  • grid - el contenedor se comporta block y los hijos (flexitems) se comportan según grid.

FLEXBOX!!!!

practica

Se aplica a un contenedor y afecta a la organizacion de los hijos que tiene. No TODOS los descendientes, solo los de los hijos directos (items).

La diferencia entre flex y grid: flex es unidireccional. Se marca un eje de distribucion y los hijos se van organizando a lo largo de ese eje.

                    display : flex;

**********

parametros flex

Propiedades aplicables al contenedor para organizar a los hijos:

  • flex-direction
    El primer parámentro es definir el eje principal. Aka 
                    flex-direction: row || column || row-reverse || column-reverse
    Nótese que el base es de izq. a derecha en row y reverse es al reves. Columna default es de arriba a abajo y reverse de abajo a arriba.
  • flex-wrap
    propiedad que hace uqe cuando no queda espacio en el div se continue en una seguienrte columna o fila dependiendo. 
                        flex-wrap: wrap || nowrap || wrap-reverse
  • flex-flow
    !! forma abreviada , se admiten dos valores, la parte de flex direction y flex-wrap. así pues: 
                flex-flow: row||column||row-reverse||column-reverse   wrap||nowrap||wrap-reverse
  • gap
    Propiedad abreviada uqe admite uno o dos valores
    • column-gap
      - Distancia entre columnas
    • row-gap
      - distancia entre filas
  • justify-content
    organizacion a lo largo del eje principal. Normalmente al eje horizontal.
    • flex-start
      - se pone al principio del eje todo unos al lado de otros.
    • flex-end
      - se pone al final del eje todo unos al lado de otros.
    • center
      - se centran sin ningun tipo de espaciado entre ellos. Aka el hueco sobrante se reparte equitativamente entre los margenes laterales.
    • space-around
      espacio igual a ambos lados de cada elemento, lo que hace que el espacio entre elementos sea el doble que el de los bordes
    • space-evenly
      - todo el espacio (bordes y entre elementos) es exactamente igual..
    • space-between
      - espacio igual entre elementos, sin margen externo..
  • align-content
    organizacion a lo largo del eje secundario. Normalmente al eje vertical.
    !!! Esta propiedad solo tiene efecto cuando hay múltiples líneas flex (es decir, cuando flex-wrap ≠ nowrap).
    • flex-start
      - se pone al principio del eje todo unos al lado de otros.
    • flex-end
      - se pone al final del eje todo unos al lado de otros.
    • center
      - se centran sin ningun tipo de espaciado entre ellos. Aka el hueco sobrante se reparte equitativamente entre los margenes laterales.
    • space-between
      el espacio entre líneas se reparte uniformemente, sin espacio en los bordes.
    • space-around
      el espacio se reparte a ambos lados de cada línea; los bordes tienen la mitad del espacio que hay entre líneas.
    • space-evenly
      - reparte el espacio sobrante entre todos los huecos , tnto entre los hijos como con los margenes.
    • stretch (valor por defecto)
      - las líneas se estiran para ocupar todo el espacio disponible.
  • align-items
    Alinea los ítems (no las líneas) a lo largo del eje secundario, dentro de cada línea flex.
    • stretch(por defecto)
      los ítems se estiran para llenar el eje secundario, si no tienen una altura/anchura fija.
    • flex-start
      - se pone al principio del eje todo unos al lado de otros.
    • flex-end
      - se pone al final del eje todo unos al lado de otros.
    • center
      - se centran sin ningun tipo de espaciado entre ellos. Aka el hueco sobrante se reparte equitativamente entre los margenes laterales.
    • baseline
      - los ítems se alinean según la línea base del texto (muy útil para texto o ítems de distintas alturas).

propiedades aplicables a los hijos del contenedor flex:

  • order
    - Define el orden visual del ítem dentro del contenedor, independientemente del orden del HTML.
    Cuanto menor sea el valor, antes aparece el ítem.
    !!! Valores pueden ser negativos, cero o positivos.
  • flex-grow
    - Controla cuánto crece un ítem para ocupar el espacio sobrante del contenedor.
    Si todos tienen 0, ninguno crece (valor por defecto).
    !!El espacio sobrante se reparte proporcionalmente a sus flex-grow.
    Explicacion: Define cómo crecen los elementos hijos cuando sobra espacio en el contenedor flex.

    Cada ítem recibe una porción del espacio sobrante en proporción a su valor de flex-grow. Si todos los hijos tienen el mismo valor, crecen por igual. Si un hijo tiene un valor mayor, crecerá más.

    .container {
    display: flex;
    width: 600px;
}

.a {
    flex-grow: 1;
}

.b {
    flex-grow: 2;
}

    Supongamos que cada ítem mide 100px inicialmente. El contenedor mide 600px, así que sobran 400px. El navegador reparte ese espacio según los valores:

    • Total de "puntos": 1 + 2 = 3
    • El ítem A recibe 1/3 del espacio sobrante → 133px
    • El ítem B recibe 2/3 del espacio sobrante → 266px

    Resultado final:

    • A → 100 + 133 = 233px
    • B → 100 + 266 = 366px

    Valor por defecto: flex-grow: 0; (no crece)

  • flex-srink
    - Controla cuánto se encoge un ítem cuando no hay suficiente espacio.
    !! Si lo pones a 0, el ítem no se reduce aunque no haya espacio.
    Explicación: Define cómo se encogen los elementos hijos cuando el contenedor es más pequeño que la suma de los tamaños base.

    El valor indica qué parte de la reducción total asumirá cada ítem (de forma proporcional). Si todos tienen el mismo valor, se encogen por igual; si uno tiene un valor mayor, se encogerá más.

    .container {
    display: flex;
    width: 300px;
}

.a, .b {
    flex-basis: 200px;
}

.a {
    flex-shrink: 1;
}

.b {
    flex-shrink: 2;
}

    Cada ítem quiere medir 200px, pero el contenedor solo tiene 300px (faltan 100px en total).
    El navegador reparte esa reducción según los valores de flex-shrink:

    • Total de "puntos": 1 + 2 = 3
    • A pierde 1/3 de 100px → 33px
    • B pierde 2/3 de 100px → 67px

    Resultado final:

    • A → 200 - 33 = 167px
    • B → 200 - 67 = 133px

    Valor por defecto: flex-shrink: 1; (se puede encoger)

    Resumen rápido
    Situación Propiedad Qué hace Valores comunes
    Sobra espacio flex-grow Hace que los ítems crezcan proporcionalmente 0 (no crece) o >0
    Falta espacio flex-shrink Hace que los ítems se encojan proporcionalmente 0 (no se encoge) o >0

    Consejo: normalmente se usa la forma abreviada:

    flex: grow shrink basis;

/* Ejemplos comunes */
flex: 1;          /* = flex: 1 1 0% */
flex: 0 1 auto;   /* no crece, sí se encoge */
flex: 1 0 200px;  /* crece, no se encoge, base 200px */
  • flex-basis
    -Define el tamaño base inicial del ítem antes de distribuir espacio.
    Puede considerarse como el “ancho” o “alto” inicial según la dirección del eje principal.
    !!Si está en auto, se usa el tamaño del contenido o de width/height.
  • align-self
    -Permite anular la alineación vertical individual de un solo ítem, sobreescribiendo align-items del contenedor.

GRID

practica

(Igual que flexbox) Se aplica a un contenedor y afecta a la organizacion de los hijos que tiene. No TODOS los descendientes, solo los de los hijos directos.

Grid hace referencia a la parrilla,. es decir es una cuadricula y es bidireccional, no como flex. En vez de basarse en ejes que es o que hace flex, se basa en filas y columnas como si fuese una tabla.

However, la diferencia con un table es que es modificable con cambios de pantalla, haciendola responsive

**********

Suele tener más propiedades que flex para hacer loo mismo, pero tambien concede más posibilidades.

Igual qeu flexbox se basa en un contenedor con cosas dentro. El grid se mete al contenedor y los hijos pierden su propiedad de block o inline y se vuelven grid-item. Para ello se crea una cuadricula estableciendo las columnas y las filas. Se puede meter explicita (configurandolo desde el código) o implicitamente ( que lo asuma el programa de por si) en caso de que se creen más flias.
La cuadricula puede ocupar todo el contenedor o no. De ahi que se pueda usar justify content y align content( creo).. Pero en este caso como no hablamoms de ejes, justify siempre se aplica a las columnas y align a las filas.
Así mismo el contenido de una de las celdas puede ser más pequeño que el espacio reservado paara ello. Para ello aparte del align-itme, tambina hay justify intem (cosa que no habia en flex lol)

Cuándo definimos un grid se definen unas lineas numeradas, incluyendo o que serian los bordes. De numerarlos en negativo se contarian desde el lado contrario de l que estamos acostumbraods. (i.e columnas:: normal-> derecha izquierda; negativo -> izq derecha. Y lo mismo con las filas). como dato se le puedn dar nombres a las linesa a modo: inicioFila2

.

  • Pista
    Se entiende como una pista todo la informacion que hay entre dos lineas consecutivas
  • Linea
    Van de borde a borde en la grid. (los bordes tambine son líneas)
  • Celda
    Unidad minima en un grid
  • Área
    Conjunto de celdas consecutivas, minimo 1 celda. Always cestructura cuadrática
  • Canal
    Distancia entre uana celda y la de al lado (GAP)

Propiedades de Grid Propiedades del contenedor:
  • display
    Establece la distribucion de los hijos en grid. 
                            display: grid||inline-grid
    No suele hacer nada de por si porlo qeu hay que definir la grid:
  • Definir explicitamente nuevas celdas:
    • grid-template-columns
      determina las columnas que tendrá la grid, se le meten tantos valores como columnas queramos, modo en px, %, etc.. Si se le meten 3 valores se haran 3 columnas con esos anchos.
      Unidades de medida:
      • px, %, cm...
      • !! Fracción (fr): recalcula en proporción del hueco sobrante (no ocupado), lo que permite diseños responsive.
      • !! Repeat: repite lo puesto entre paréntesis en formato repeat(número, medida).
      • A veces el contenido supera el tamaño establecido; aquí entran en juego las propiedades max-content y min-content, que ajustan la celda al tamaño más grande o más pequeño de su contenido (según si se aplican a columnas o filas).
      • minmax(mínimo, máximo): establece un valor mínimo y máximo, por lo que la columna o fila oscilará entre esos límites.
      • fit-content(medida): utiliza como valor de medida el menor entre la medida dada y el max-content.
      • También existen los valores auto y none. 
              grid-template-columns: 150px 40% 2fr repeat(2, 1fr) min-content minamx(200px, 30%);
      Se le pueden dar nombres a cada columna (a las lineas mas bien con un [] antes de cada valor) para que nos resulte mas sencillo a la hora de delimitar areas. 
          grid-template-columns: [iniCol1] 200px [finCol1 iniCol2]2fr [finCol2 iniCol3] 1fr [finCol3];
    • grid-template-rows
      Lo mismo pero para las filas y el valos valdran lo alto que son.
    • grid-template-columns
    • grid-template-areas
      cada "" es una fila y lo que vaya dentro son los items que van en esa fila (necesitamos los nombres de grid-area)
  • Definir implicita nuevas celdas:
    • grid-auto-columns
      Definicion automatica para las nuevas columnas que se crean de forma implicita. Se crean con esos valores.
    • grid-auto-rows
      Lo mismo que lo anterior pero para filas
  • grid-auto-flow
    le flow que sigue rellenando, si hay mas hijos se crean en la direccion que se especifica-. Similar al flex-direction 
    grid-auto-flow: column||row
