Ajustes en el CSS:


Estructura Global con Grid:
Vamos a aplicar CSS Grid a la estructura principal del layout para cumplir con la disposición de las áreas.


Área Lateral con Flexbox: El menú y el formulario de contacto pueden utilizar Flexbox para organizar sus elementos.


Posicionamiento de las tarjetas de empleados: Las tarjetas de los empleados deben tener un float en lugar de Flexbox o Grid para cumplir con los requisitos.

Explicación de los Cambios:


Grid para la estructura principal (content-container): Se usa grid-template-columns para dividir la página en dos partes: un 30% para el menú lateral y un 70% para el contenido principal.


Menú lateral y formulario: Estos se organizan con Flexbox para asegurar que los elementos estén alineados verticalmente.


Grid para las tarjetas de empleados: Se organiza en tres columnas usando grid-template-columns: repeat(3, 1fr) y gap para establecer el espaciado.


Uso de Float: Las tarjetas de los empleados están configuradas con float: left para cumplir con los requisitos.
