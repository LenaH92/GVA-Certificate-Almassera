          muestra un patron qwue tiene qu seguir lo que se meta, entre corchetes los valores que se pueden esribir y tntre curlies la cantidad de caracteres que se pueden poner p.e pattern="[0-9]{5}"
          Ejemplos
          • Solo MAYÚSCULAS → pattern="[A-Z]+"
          • Solo minúsculas → pattern="[a-z]+"
          • Letras y espacios → pattern="[A-Za-z ]+"
          • Número entre 1 y 99 (sin ceros delante) → pattern="[1-9][0-9]?"
          • Código postal de 5 números → pattern="\d{5}"
          • Contraseña con mínimo 8 caracteres → pattern=".{8,}"
          • Contraseña con mayúscula, minúscula, número y símbolo → pattern="(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&]).{8,}"
          • Texto que empiece por una letra → pattern="^[A-Za-z].*"
          • Teléfono de 9 dígitos → pattern="\d{9}"
          • Fecha en formato DD/MM/YYYY → pattern="\d{2}/\d{2}/\d{4}"
          • Nombre sin números (incluye acentos y ñ) → pattern="[A-Za-zÁÉÍÓÚÜÑáéíóúüñ ]+"
          • Placa de coche ABC-123 → pattern="[A-Za-z]{3}-\d{3}"
          • Color hexadecimal (#RRGGBB) → pattern="#[0-9A-Fa-f]{6}"
          • Aceptar solo “sí” o “no” → pattern="sí|si|no"

      • Botones!! Tipos:
        • button
          Botón genérico que **no hace nada por sí solo**. Se suele usar para ejecutar código JavaScript con onclick o eventos similares.
        • submit
          Botón para **enviar un formulario**. Por defecto envía los datos al action del formulario usando el method definido. Atributos específicos:
          • formaction
            URL alternativa a la que se enviará el formulario al pulsar este botón. Sobrescribe el action del form.
          • formmethod
            Metodo de envío (get o post). Sobrescribe el method del form.
          • formenctype
            Tipo de codificación de datos (multipart/form-data, application/x-www-form-urlencoded, text/plain). Sobrescribe el enctype del form.
          • formtarget
            Ventana donde se abrirá la respuesta (_self, _blank, etc.). Sobrescribe el target del form.
          • formnovalidate
            Booleano, permite **omitir la validación HTML5** de los campos al enviar con este botón.
        • reset
          Botón para **restablecer los campos del formulario** a sus valores iniciales. No envía datos, simplemente borra lo que el usuario ha escrito y vuelve a los valores originales definidos en el HTML.
